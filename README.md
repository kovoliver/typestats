# TypeStats

**TypeStats** is a comprehensive, open-source TypeScript library designed for robust statistical analysis, mathematical modeling, and hypothesis testing.

## 📌 Project Purpose & Status

This project was primarily created as a learning endeavor to deeply understand, practice, and memorize statistical calculations. 

**Note on Reliability:** Although this is currently a test version, this does not imply that the calculations are flawed. The overarching goal is for the final form to be completely reliable. Even in its current state, the vast majority (if not all) of the implemented calculations are assumed to be flawless and mathematically sound.

## 🧮 Implemented Calculations & Features

Based on the architectural structure, the library encompasses the following statistical and mathematical capabilities:

### 1. Probability Distributions (`calculations/distributions/`)
* **`normalDist.ts`**: Calculations for the Normal (Gaussian) distribution, including Probability Density Function (PDF), Cumulative Distribution Function (CDF), and quantiles (Z-scores).
* **`studentDist.ts`**: Student's t-distribution calculations, crucial for small sample sizes and unknown population variances.
* **`chiSquareDist.ts`**: Chi-Square ($\chi^2$) distribution calculations, utilized for goodness-of-fit and independence tests.

### 2. Inferential Statistics (`calculations/inference/`)
* **`estimations.ts`**: 
  * Point estimations.
  * Confidence intervals for population means, proportions, and variances.
  * Standard error calculations.
* **`hypothesis.ts`**: 
  * Parametric tests (e.g., Z-tests, One-sample and Two-sample T-tests).
  * Analysis of Variance (ANOVA).
  * Non-parametric tests (e.g., Chi-Square test for independence).
* **`Trend.ts`**: 
  * Linear regression and trend line fitting.
  * Moving averages and time-series estimations.
  * Slope and intercept calculations.

### 3. Descriptive Statistics (`calculations/statistics/`)
* **`univariate.ts`**: 
  * Measures of central tendency (Mean, Median, Mode).
  * Measures of dispersion (Variance, Standard Deviation, Range, Interquartile Range).
  * Shape of distribution (Skewness, Kurtosis).
* **`bivariate.ts`**: 
  * Covariance.
  * Pearson correlation coefficient ($r$).
  * Spearman's rank correlation.
  * Measures of association (e.g., Cramér's V).
* **`FrequencyTable.ts`**: 
  * Construction of frequency distributions.
  * Absolute, relative, and cumulative frequencies.
  * Class interval grouping.

### 4. Mathematical Models (`calculations/math/`)
* **`Matrix.ts`**: 
  * Matrix instantiation and manipulation.
  * Core linear algebra operations (Addition, Multiplication, Transposition).
  * Determinants and Matrix Inversion (essential for multiple regression models).

### 5. Utilities & Types (`calculations/utils/` & `types.ts`)
* **`numberUtils.ts`**: Core mathematical helpers, factorial calculations, safe rounding, and floating-point corrections.
* **`testAndEstimationUtils.ts`**: Shared helper functions for degrees of freedom ($
u$), critical value lookups, and p-value formatting.
* **`types.ts`**: Global TypeScript interfaces and type aliases ensuring strict type safety across all modules.
